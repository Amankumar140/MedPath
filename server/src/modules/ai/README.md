# AI Module

This module manages backend integration orchestration and request translation between the Node.js API and the Swasthya AI Core API platform.

## Responsibilities
- Calling `swasthya.service.js` methods
- Processing raw symptom outputs into structured recommendation triggers
- Mapping user session context into conversational inputs for Swasthya AI Core
- Managing background jobs related to heavy rank calculations

*To be fully implemented in a future phase.*
